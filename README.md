Kesimpulan

Berdasarkan hasil praktikum dapat disimpulkan bahwa perintah CREATE USER digunakan untuk membuat akun pengguna baru pada MariaDB/MySQL. Praktikum menunjukkan bahwa ketelitian dalam menulis sintaks SQL sangat penting karena kesalahan kecil, seperti salah penulisan kata IDENTIFIED, dapat menyebabkan munculnya ERROR 1064 (42000). Setelah sintaks diperbaiki, proses pembuatan user berhasil dilakukan. Praktikum ini juga memberikan pemahaman bahwa setiap user dapat diberikan hak akses tertentu sesuai kebutuhan, sehingga keamanan dan pengelolaan database menjadi lebih terstruktur.
